# Нагрузка процессора

Нагрузка распределилась неравномерно, но на несколько логических ядер. При выполнении программы процессор был нагружен на 17%, при её остановке нагрузка 3-9% => программа занимала 8-14%.
Общая нагрузка считает все подпроцессоры вместе. Поэтому процент нагрузки на общем графике меньше, чем на отдельном ядре.

Вывод: программа нагружает не сразу все логические ядра. Возможно другой поток был нагружен другой программой, а наша программа занимает один поток.

# Дополнительное задание

Тактовая частота процессора на данном пк:

3,3-4,3 ГГц = 3 300 000 000 --- 4 300 000 000 тактов/с

Если сравнить количество тактов в секунду и количество итераций нашей программы в секунду, то будет серьёзное отличие. Итерация может выполнятся несколько тактов, но в один такт может выполняться несколько операций. Операция != такт CPU.
